# آیکون‌های اکستنشن دستیار پولو (BCSPolo NewTab)

این پوشه شامل آیکون‌های استاندارد اکستنشن گوگل کروم بر اساس طراحی متریال دیزاین ۳ (Material You) است.

### فایل‌های موجود:
1. `icon.svg`: فایل وکتور اصلی با پالت رنگی آبی گوگل (`#1a73e8`)، فرم Squircle متریال، المان تقویم و تیک انجام کار.
2. `icon-16.png`: آیکون سایز ۱۶ پیکسل برای نوار عنوان و Favicon مرورگر.
3. `icon-48.png`: آیکون سایز ۴۸ پیکسل برای صفحه مدیریت اکستنشن‌ها (`chrome://extensions`).
4. `icon-128.png`: آیکون سایز ۱۲۸ پیکسل با وضوح بالا برای Chrome Web Store و نوتیفیکیشن‌های سیستم.

### بازتولید آیکون‌ها:
در صورت تمایل به تغییر استایل یا رنگ، می‌توانید با اجرای دستور زیر در ترمینال آیکون‌های PNG را مجدداً تولید کنید:
```bash
node scripts/generate-icons.js
```
